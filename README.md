One word, first thought: **petrichor** — the scent of rain on dry earth.

The competition asks for exactly one word, the first that comes to mind, and a judge compares words two at a time on which is more interesting. Surprise, vividness and a spark of wit beat safe filler. Petrichor is a smell everyone knows instantly in a word most readers have never seen: surprising, vivid, specific, and it sounds like what it means. Against the safe field — love, hope, dream, serendipity — it wins on the judge's first criterion (surprise) before the rest even matter.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```

The program writes the single word to `/output/entry.txt` (9 characters, within the 1–24 gate).
